# Changelog

Все изменения нумеруются по порядку: Patch 1, Patch 2, Patch 3 и т.д.

## Patch 1
- **hotkey.py**: `_thread_func` обёрнут в `try/except/finally`. Раньше любая ошибка Win32 API убивала daemon-нить молча, теперь логируется как CRITICAL и гарантированно выполняется очистка ресурсов.
- **recorder.py — `_update_volume_loop`**: тело обёрнуто в `try/except`. Исключения больше не крашат Tkinter main loop.
- **recorder.py — `stop_recording`**: `np.concatenate` защищён `try/except`. Несовместимые аудио-чанки больше не вызывают crash.
- **recorder.py — `transcribe_audio`**: `self.root.after()` заменён на `_safe_after()`, перехватывающий `TclError` при обращении к уничтоженному Tkinter (быстрый рестарт/выход во время транскрипции).
- **tray_icon.py — `_run_icon`**: обёрнут в `try/except`. Ошибка pystray больше не проглатывается daemon-нитью.

## Patch 2
- **main.py**: Добавлен `faulthandler` в самом начале (до импортов). Теперь segfault и прочие краши в C-расширениях (CTranslate2, PortAudio, CUDA) пишут дамп стека всех потоков в `logs/crash_dump.log`.
- **recorder.py — `record_audio` callback**: callback sounddevice обёрнут в `try/except`. Исключения из PortAudio-тремора (C-поток) больше не вызывают segfault, а логируются.
- **recorder.py**: Добавлен периодический `flush_logging()` каждые ~3 секунды и после ключевых операций (stop_recording, transcribe_audio). Логи теперь гарантированно сбрасываются на диск даже при внезапном краше.
- **logger_utils.py**: Добавлена функция `flush_logging()` и вызывается в `shutdown_logging()`. Принудительно сбрасывает все handler'ы на диск.
- **tray_icon.py — `_update_state`**: обёрнут в `try/except`. Ошибка доступа к `icon.icon` больше не крашит очередь команд трея.

## Patch 3 (подготовка к релизу 1.0.0)
- **main.py**: Убран жёстко зашитый путь к кэшу Hugging Face (`D:/ProgramData/.cache/huggingface`). Теперь приоритет такой: переменная окружения `HF_HOME` > старый кэш на этом ПК > локальная папка `hf_cache/` рядом с проектом (создаётся автоматически). Программа становится переносимой на другие машины.
- **main.py**: Добавлена константа `APP_VERSION = "1.0.0"`, версия пишется в лог при старте.
- **gui.py — `_update_autostart`**: Убран запасной путь `D:\programs\python3.11.8\pythonw.exe`. Теперь используется `shutil.which("pythonw.exe")` с понятным сообщением об ошибке, если Python не в PATH.
- **start.bat**: Теперь ищет `pythonw.exe` в PATH (с запасным вариантом на исходной машине) и показывает понятное сообщение, если Python не найден, вместо тихой ошибки.
- **gitignore.txt / gitattributes.txt**: Переименованы в `.gitignore` / `.gitattributes` (Git игнорировал их под прежними именами). В `.gitignore` добавлена папка `hf_cache/`.
- **README.md**: Обновлён под релиз — убрано предупреждение о нестабильности, ссылка на Google Drive заменена на GitHub Releases и `git clone`, исправлен размер модели (около 3 ГБ), обновлён диапазон Python (3.9–3.12), описание кэша модели и автозапуска приведены в соответствие с кодом.
- **CHANGELOG.md**: Убрана служебная инструкция для ИИ, история патчей дополнена.

## Release 1.0.0
- Первый публичный релиз на GitHub. Функциональность: запись с микрофона, распознавание Faster-Whisper (CPU/CUDA), глобальный хоткей, системный трей, автозапуск, обработка аудио (усиление, нормализация, шумоподавление, темп), детектор тишины, озвучивание статусов (SAPI5), копирование результата в буфер обмена, детальное логирование и дампы при крашах.

## Patch 4
- **watchdog.bat**: убрана защита от завершений пользователя — теперь любое завершение программы (включая "Выход" из трея), кроме намеренного перезапуска, считается падением, и watchdog перезапускает программу. Режим `stopped` удалён.
- **watchdog.bat**: добавлен режим `wait_boot` — после перезапуска программа получает до 180 секунд (`BOOT_WAIT`) на запуск, прежде чем watchdog решит, что она не поднялась (долгая загрузка torch/whisper больше не вызывает ложные перезапуски). `RESTART_WAIT` увеличен с 90 до 180 секунд.
- **watchdog.bat**: перед перезапуском пишет маркер `logs/restart_info.flag` со значением `watchdog` для инфо-окна.
- **main.py**: добавлен именованный мьютекс Windows — защита от двух одновременно запущенных экземпляров. Второй экземпляр завершается сразу, ещё до тяжёлых импортов (защита от гонки, когда watchdog перезапускает программу, а прошлая копия ещё грузится).
- **gui.py**: добавлен класс `RestartInfoWindow` — одноразовое немодальное инфо-окно о причине перезапуска ("перезапущена watchdog-ом" или "перезапущена пользователем"). Не блокирует работу горячих клавиш.
- **logger_utils.py**: добавлены функции `write_restart_info()` / `read_and_clear_restart_info()` — маркер причины перезапуска (`watchdog` / `user`) для инфо-окна.
- **recorder.py**: при старте читает маркер причины и показывает инфо-окно; при перезапуске из трея/настроек пишет маркер `user`; инфо-окно скрывается вместе с главным окном.
- **tray_icon.py**: убран вызов `write_restart_flag("exit")` — "Выход" из трея больше не останавливает watchdog.

## Patch 5
- **hotkey.py**: полная поддержка комбинаций клавиш. `parse_hotkey()` разбирает строки вида `f8`, `ctrl+shift+f9`, `left alt+caps lock`, `win+d` (модификаторы ctrl/shift/alt/win, левые/правые варианты, F1-F24, буквы, цифры, спецклавиши, caps lock и т.д.). Раньше `_parse_vk()` понимал только одну клавишу, поэтому дефолтный хоткей `left alt+caps lock` молча не регистрировался. Неверные комбинации теперь отбрасываются с понятной ошибкой.
- **hotkey.py**: уникальное имя класса окна (`HotkeyHandlerWindow_{id}`) — повторное создание HotkeyHandler в одном процессе больше не падает на RegisterClass.
- **gui.py — `save_settings`**: хоткей валидируется через `parse_hotkey()` перед сохранением — пользователь сразу видит ошибку в окне настроек.
- **recorder.py**: `input_device` из настроек теперь реально используется — `sd.InputStream(..., device=...)`. Добавлена функция `resolve_input_device()`: принимает индекс или имя устройства, проверяет, что это входное устройство, иначе предупреждает в логе и использует устройство по умолчанию.
- **main.py**: в `DEFAULT_SETTINGS` добавлен ключ `"input_device": None`.
- **recorder.py — `_on_model_loaded`**: если хоткей не зарегистрировался, статус показывает причину вместо молчаливого игнора.
- **recorder.py — `_on_model_error`**: при ошибках CUDA/cuDNN/GPU к сообщению добавляется подсказка про смену устройства на CPU.
- **recorder.py**: при включённом `enable_time_stretch` и отсутствии pyrubberband/rubberband при старте пишется предупреждение в лог.
- **main.py**: убран собственный выбор пути к кэшу Hugging Face (включая жёсткий путь `D:/ProgramData/.cache/huggingface` и папку `hf_cache/` рядом с проектом). Теперь модель скачивается в стандартный кэш Hugging Face (`~/.cache/huggingface`), путь можно задать переменной окружения `HF_HOME`. Универсально для любого ПК.
- **README.md**: описание первого запуска обновлено — модель сохраняется в стандартный кэш Hugging Face.
